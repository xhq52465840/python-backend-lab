## 怎么用（固定流程）

1. `git pull`
2. 进入本周目录，再进**今天**的文件夹，例如 `week1-fastapi/day01-get-post/`
3. 先看当天的 `VIDEOS.md` + `NOTES.md`，再按 `README.md` 做任务
4. 在**当天文件夹里**改代码、跑通
5. 提交并推送（建议分支 `study/week1-day01`）
6. 老师会 review 你当天的提交
