# 验收机制（老师怎么认定你「今天过关」）

## 1. 上午 10:00（工作日）——先考再定课

1. 随机抽查「迄今学过的全部内容」（入学摸底则考基础）。
2. 你先交卷。
3. 老师分流并写入 `progress/TODAY.md`：
   - **强化日**：只复习薄弱点 + 重做练习
   - **新课日**：推进总课表里的下一天（day-XX）
   - **混合日**：新课减半 + 补弱
4. 在此之前，以总课表为准预习；但「正式当天任务」以 `progress/TODAY.md` 为准。

## 2. 白天——你自己学，卡壳随时交作业/报错

编码日额外硬标准（能客观验收）：

- 本地命令跑通（如 `pytest`、`uvicorn`、`docker compose`）
- 相关 PR / CI 绿灯（有要求的那天）

## 3. 傍晚 18:00（工作日）——口头 + 测验验收

老师会问：

1. 今天 `TODAY.md` 清单完成了吗？（全部 / 部分+卡点 / 请假）
2. 3 道巩固「今天实际学的」题
3. 1 道更早旧知识题

你用模板回：

```
完成度：全部完成 / 部分完成（卡在：…） / 请假
今日做了：…
测验：
1. …
2. …
3. …
4. …
```

老师批改后记入记忆；错的点会进入之后上午的抽查加权。

## 4. 阶段出口（比「一天」更大的验收）

例如 A1：week1 CRUD + 测试 + PR CI 绿 + 出门考试。  
见各 `day-XX` 文末「阶段出口」与 `DAILY_PLAN.md` 勾选。

## 5. 不是「到点才建课表」

总课表已经建好。到点做的是：**抽查 → 决定今天走总课表哪一张（或改成强化单）→ 晚上按这张验收。**
