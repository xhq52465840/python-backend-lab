# 课程表（你现在就能看的总课表）

这里不是等到早上 10 点才「发明」课程。

## 两层计划

| 层 | 文件 | 什么时候有 | 作用 |
|----|------|------------|------|
| **总课表** | 本目录 + `../DAILY_PLAN.md` + `../PATH.md` | **现在就有** | 全部学习内容、顺序、每天默认学什么、怎么算过关 |
| **当天实课** | `../progress/TODAY.md` | **每个工作日上午抽查交卷后** 才写入/更新 | 根据抽查表现决定：强化旧课 or 上新课；那天晚上按这份验收 |

所以：
- GitHub 上一直能看到「整学期课表」
- 「今天到底复习还是上新」要等抽查结果，避免日历硬推、你没学会还往下赶
